# Guía del método

Este libro de ejemplo muestra el formato de un cuaderno de estudio para Lectio. Cada sesión dura unos 40 minutos y tiene cinco pasos: lectura, recuperación con el libro cerrado, verificación, autoexamen y aplicación.

## Referencias al libro

Las indicaciones citan el capítulo y la sección, por ejemplo [[Cap. 1 › Leer no es aprender]], y nunca números de página.
